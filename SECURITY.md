# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in **QuackBoard** (for example, SQL read-only bypasses, credential encryption issues, or XSS), please **do not** open a public GitHub issue.

Instead, report it privately by emailing **ayman.m.ali148@gmail.com** or using [GitHub Security Advisories](https://github.com/aymanmali/quackboard/security/advisories/new).

Please include:
- A clear description of the vulnerability and its potential impact.
- Steps to reproduce or a minimal proof of concept.
- Any suggested mitigation if known.

We will acknowledge your report within 72 hours and work on a fix as quickly as possible.
